NeXTools

Web Tools Platform

  • Next.js 16
  • React 19
  • TypeScript
  • Tailwind CSS 4
  • CodeMirror
  • Vitest

Kumpulan 89 utility tool harian di satu situs bertema neon: dari Word Counter, JSON Formatter, dan Hash Generator sampai QR Scanner, Video Downloader, dan HTML to APK. Dibangun dengan Next.js App Router dan TypeScript, dengan pendekatan client-side first: data yang kamu tempel tidak pernah meninggalkan perangkat.

Fitur

  • 89 tool dalam 6 kategori: Teks, Konversi, Developer, AI Tools, Playground, dan Utilitas
  • Client-side first untuk mayoritas tool — teks, JSON, hash, QR, dan gambar diproses di browser
  • Lima playground dengan runtime asli: HTML/CSS/JS, Python (Pyodide + matplotlib), TypeScript, SQLite (sql.js/WASM), dan JS console
  • Tool berbasis server milik sendiri: Video Downloader (yt-dlp), HTML to APK (toolchain Android), dan HTML to Video (Chromium + ffmpeg)
  • Tiga tool AI lewat Gemini dengan rotasi key dan model, kuota berlapis per cookie/IP/global, serta fallback template
  • Halaman tool di-SSG, sitemap dan robots dinamis, plus mode maintenance dua tingkat
  • 1.500+ unit test Vitest untuk logika murni di lib/

Menjalankan

Butuh Node.js 20+. Tool AI opsional dan hanya aktif setelah GEMINI_API_KEY diisi.

npm install
npm run dev     # http://localhost:3000
npm run build   # produksi (SSG)
npm start
npm test        # vitest

Arsitektur

app/          halaman & API route
components/   UI + 89 komponen tool
lib/          logika murni + registry tool
tests/        unit test Vitest
proxy.ts      gate maintenance

NeX-Agent

AI Agent CLI

  • TypeScript
  • Node.js
  • pnpm
  • Vitest

Agent berbasis terminal dengan loop agentik, dua mode (Plan dan Build), soft workspace boundary, diff dengan konfirmasi, checkpoint dan undo, serta arsitektur multi-provider. Dibangun CLI-first dengan TypeScript strict.

Fitur

  • Loop agentik dengan dua mode: Plan (read-only) dan Build
  • Soft workspace boundary, diff dengan konfirmasi, serta checkpoint dan undo
  • Multi-provider: OpenAI-compatible dan Anthropic
  • Agent Skills lewat SKILL.md, daftar tugas live, dan render Markdown di terminal
  • File sensitif (.env, private key, kredensial) selalu minta konfirmasi, meski memakai --allow-all
  • Mendukung Termux (Android)

Instalasi

Butuh Node.js 20+, pnpm, git, dan curl. Node dan pnpm dipasang otomatis bila belum ada.

curl -fsSL https://raw.githubusercontent.com/RydzzKen/NeX-Agent/main/install.sh | bash
source ~/.bashrc
nex-agent

Di Termux, jalankan pkg install -y git dulu. Tidak perlu source ~/.bashrc. Untuk instalasi manual dari checkout:

pnpm install
pnpm build
bash install.sh

Penggunaan

nex-agent "<tujuan>"
nex-agent --mode plan "..."
nex-agent --resume <id>
nex-agent --continue
nex-agent usage today

Di mode chat tersedia slash command seperti /connect, /models, /plan, /build, /undo, dan /skills.

Arsitektur

src/
  core/       loop agentik, approvals, checkpoint
  providers/  adapter OpenAI-compatible, Anthropic
  tools/      read_file, write_file, edit_file, run_shell
  safety/     workspace, permissions, policy
  cli/        renderer, prompt, slash command

TeaScript

Bahasa Pemrograman

  • Python
  • Interpreter
  • REPL
  • Flask
  • MIT

TeaScript adalah bahasa skrip kecil bergaya JavaScript/Python yang diimplementasikan murni di Python tanpa dependensi eksternal. Proyek ini dibuat untuk mempelajari cara kerja sebuah bahasa pemrograman, dari lexer, parser, sampai evaluator, dengan REPL interaktif dan server web opsional di atas Flask.

Fitur

  • Alur lexer → parser (recursive descent) → evaluator, dengan error berposisi baris:kolom dan cuplikan baris sumber
  • Sintaks inti: let, if / else if / else, while, for ... in, break/continue, ternary ? :, closure, dan parameter default
  • try { ... } catch e { ... } menangkap error runtime TeaScript sekaligus exception Python dari pyimport
  • String interpolasi "${...}", method string, slicing, indeks negatif, serta operator in/not in
  • Modul import/from dengan stdlib math, text, collections, env, plus pyimport untuk library Python apa pun
  • Web.app() di atas Flask dan tea-web untuk playground/API; 27 fungsi bawaan, REPL interaktif, dan 216 test

Menjalankan

Butuh Python 3.8+. Tanpa dependensi wajib; Flask hanya diperlukan untuk fitur web (tea-web).

pip install "teascript @ git+https://github.com/RydzzKen/TeaScript.git"
tea tes.tea
tea check tes.tea
tea info
tea

Arsitektur

teascript/
  lexer.py      teks → token (string, escape, interpolasi)
  token.py      definisi token & keyword
  parser.py     token → AST (recursive descent)
  ast_nodes.py  definisi node AST
  evaluator.py  eksekusi AST + builtins + modul + web
  errors.py     error ber-posisi
  repl.py       REPL interaktif
  web.py        server Flask (API + tea-web)
  cli.py        argumen command line
  modules/      stdlib: math, text, collections, env
